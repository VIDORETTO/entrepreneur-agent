# Política de perguntas

Não perguntar orçamento, cargo, dor ou autoridade quando preço, oferta e dados
operacionais já bastarem para o próximo passo. Reutilizar fatos confirmados e
perguntar apenas o primeiro campo realmente ausente. Uma pergunta pode agrupar
campos do mesmo passo operacional, mas não uma entrevista de qualificação.

Uma pergunta de recomendação só é válida quando a resposta muda a escolha ou o
fluxo. Se o comprador já escolheu, seguir pelo mecanismo permitido.
