# Código de conduta

Queremos uma comunidade técnica acolhedora, objetiva e segura. Participantes
devem tratar outras pessoas com respeito, aceitar críticas construtivas e evitar
assédio, discriminação, intimidação, divulgação de dados privados ou conteúdo
sexual indesejado.

Este código vale para issues, pull requests, discussões, revisões, eventos e
outros espaços em que alguém represente o projeto. Mantenedores podem editar ou
remover conteúdo e restringir a participação quando necessário para proteger a
comunidade.

Relate incidentes pelo canal privado indicado em `SECURITY.md`. Não inclua dados
pessoais em relatos públicos. Os mantenedores analisarão o contexto, preservarão
a confidencialidade possível e adotarão uma resposta proporcional, que pode ir
de orientação privada à exclusão permanente dos espaços do projeto.
