# Política de segurança

## Versões suportadas

Enquanto o projeto estiver em alpha, apenas a revisão mais recente da branch
principal recebe correções de segurança. Ainda não há promessa de estabilidade
de API nem suporte de produção.

## Como reportar

Não publique vulnerabilidades, credenciais, dados de clientes ou provas de
conceito destrutivas em uma issue pública. Use o recurso **Report a
vulnerability** na aba Security do repositório GitHub. Se esse recurso não
estiver habilitado, abra uma issue sem detalhes sensíveis solicitando um canal
privado aos mantenedores.

Inclua versão ou commit, impacto, pré-condições e uma reprodução mínima com
dados fictícios. Não teste contra sistemas de terceiros ou ambientes de
produção sem autorização explícita.

## Escopo atual

O checkout, o pagamento, a agenda, o canal e a transferência humana presentes
neste repositório são simuladores locais. Relatos de que esses simuladores não
executam uma transação real não são vulnerabilidades; qualquer caminho que
contorne políticas, misture negócios, exponha o SQLite ou repita um efeito é.
