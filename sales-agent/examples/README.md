# Negócios fictícios

Os pacotes completos são gerados por `vendedor examples` a partir de
`sales_agent.config.example_package`. Os diretórios abaixo documentam o papel
de cada demonstração e não contêm dados reais.

| Diretório | Modalidade | Próximo passo |
|---|---|---|
| `b2c-physical-direct` | camiseta física B2C | checkout preparado |
| `b2b-direct` | licenças padronizadas B2B | checkout preparado |
| `b2c-consultative` | reforma de serviço | proposta após escopo |
| `digital-access` | curso digital | checkout e liberação condicionada a pagamento confirmado |
